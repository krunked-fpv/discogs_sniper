## Domain Invariants
1. **Zero-Preflight CORS Rule (`api.discogs.com`):** Browser `fetch()` calls to `https://api.discogs.com` MUST pass `?token=<encoded>` in the URL with **ZERO custom HTTP headers** (never set `Authorization` or `User-Agent`). Enforce token-bucket pacing (`1.25s` authenticated, `3.1s` anonymous, `65s` cooldown on HTTP `429`) and 6-hour IndexedDB caching (`krunked_sniper_idb_v3`).
2. **Shadow-Cookie Security Boundary (`krunked-cookie-vault-v1`):** If healing UI preferences (`lightingMode`, filters, muted/drop-only sellers, target prices), NEVER mirror any key matching `/token|pat|secret|auth/i` (`krunked_discogs_token`, `krunked_sniper_github_pat_v3`, etc.) or heavy caches into cookies. Credentials remain strictly in `localStorage`.
3. **XSS & Entity Safety:** Decode multi-escaped entities defensively (`decodeHtmlEntities`) strictly BEFORE `escapeHtml()`, and sanitize all external URLs with `sanitizeHttpUrl()`. Never interpolate unescaped marketplace data into `innerHTML`.
4. **Zero-Autoplay Audio & Turntable DSP:** 30s studio previews (iTunes Search + Deezer JSONP fallback) play ONLY on explicit user gesture; keep `preservesPitch = false` RPM/pitch coupling, synthesized crackle (`OFF`/`WARM`/`DUSTY`), and 32-band FFT visualizer intact.
5. **Preserve Compiler & Test Contracts:** Retain `/* __INJECT_STYLES_CSS__ */`, `<script id="sniper-prebaked-state" type="application/json">__INJECT_SNIPER_STATE_JSON__</script>`, and `// __INJECT_APP_JS__` in `src/template.html`, plus all test-asserted DOM IDs (`btn-toggle-uv`, `btn-sync-live-wantlist`, `vault-live-sync-status`, `turntable-platter-canvas`, `cmd-palette-backdrop`, `inspect-modal-backdrop`).
6. **PWA Network Bypass (`sw.js`):** Never cache `api.discogs.com`, `api.github.com`, `raw.githubusercontent.com`, `itunes.apple.com`, `api.deezer.com`, or live `/discogs_collection/data/`.
